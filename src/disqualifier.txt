# DISQUALIFICATION RULES
# =============================================================================

# +--------------------------------------+--------------------------------------------------------------+--------------+
# | Field                                | Condition                                                    | Result       |
# +--------------------------------------+--------------------------------------------------------------+--------------+
# | years_of_experience                  | < 4                                                          | Disqualify   |
# +--------------------------------------+--------------------------------------------------------------+--------------+
# | country && willing_to_relocate       | country != India AND willing_to_relocate = False            | Disqualify   |
# +--------------------------------------+--------------------------------------------------------------+--------------+
# | location && willing_to_relocate      | location NOT IN                                              | Disqualify   |
# |                                      | [Noida, Pune, Hyderabad, Pune, Mumbai, Delhi NCR,           |              |
# |                                      |  Bengaluru/Bangalore] AND willing_to_relocate = False       |              |
# +--------------------------------------+--------------------------------------------------------------+--------------+
# | open_to_work_flag                    | False, but candidate is active:                             | Can be in    |
# | last_active_date                     |   - last_active < 1 month                                   | list         |
# | applications_submitted_30d           |   - applications_submitted_30d > 3                          |              |
# | avg_response_time_hours              |   - avg_response_time < 2 days                              |              |
# +--------------------------------------+--------------------------------------------------------------+--------------+
# | open_to_work_flag                    | True, and candidate is active:                              | Can be in    |
# | last_active_date                     |   - last_active < 1 month                                   | list         |
# | applications_submitted_30d           |   - applications_submitted_30d > 1                          |              |
# | avg_response_time_hours              |   - avg_response_time < 3 days                              |              |
# +--------------------------------------+--------------------------------------------------------------+--------------+
# | open_to_work_flag                    | False, and candidate is NOT active:                         | Disqualify   |
# | last_active_date                     |   - last_active > 1 month                                   |              |
# | applications_submitted_30d           |   - applications_submitted_30d < 1                          |              |
# | avg_response_time_hours              |   - avg_response_time > 2 days                              |              |
# +--------------------------------------+--------------------------------------------------------------+--------------+
# | open_to_work_flag                    | True, and candidate is NOT active:                          | Disqualify   |
# | last_active_date                     |   - last_active > 1 month                                   |              |
# | applications_submitted_30d           |   - applications_submitted_30d < 1                          |              |
# | avg_response_time_hours              |   - avg_response_time > 2 days                              |              |
# +--------------------------------------+--------------------------------------------------------------+--------------+
# | current_company / career_history     | Only service companies in career history:                   | Disqualify   |
# |                                      | [TCS, Infosys, Wipro, Accenture, Cognizant, Capgemini]      |              |
# |                                      |                                                              |              |
# |                                      | Any other company present (past or current)                 | Can be in    |
# |                                      |                                                              | list         |
# +--------------------------------------+--------------------------------------------------------------+--------------+
# | current_title                        | Matches non-coding roles (regex), e.g.                      | Disqualify   |
# |                                      | "manager", "executive", etc.                                |              |
# +--------------------------------------+--------------------------------------------------------------+--------------+
